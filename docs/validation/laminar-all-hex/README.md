# FlowLab laminar all-hex validation campaign

This directory is the human-readable control surface for the completed
`laminar-all-hex-v4` campaign. Machine-readable manifests, scheduler events,
cell reports, issue records, and aggregate evidence live under:

- `benchmarks/cases/open-boundary/campaigns/2026-07-16-laminar-all-hex-v4-campaign-r1`
- `benchmarks/cases/open-boundary/campaigns/2026-07-16-laminar-all-hex-v4-followups`

V4 numerically verifies the bounded desktop-only structured all-hex laminar
regime. The completed [FDA nozzle Re=500 campaign](../fda-nozzle-re500/README.md)
did not pass all frozen experimental gates, so desktop execution remains
unavailable. It cannot broaden the
claim to CAD, curved or hybrid meshes, turbulence, transients, multiphase
flow, compressibility, materially different boundary conditions, or native
performance. Mobile is out of scope.
